感谢你对 InterCog：跨学科推理引擎（Interdisciplinary Reasoning Engine） 的兴趣。
InterCog 的目标是让 AI 拥有真正的跨学科推理能力，让深层学科与元学科的力量成为所有人的基础设施。

InterCog 以 MIT 协议开源，我们欢迎所有形式的贡献：
学科扩展、场景模板、证据库补充、权重优化、文档改进、使用案例分享等。

本指南将帮助你顺利参与 InterCog 的建设。

1. InterCog 的核心理念
InterCog 的设计基于一个核心信念：

深层学科（经济学、社会学、心理学、认知科学）与元学科（系统论、证据学、方法论）对分析复杂问题具有不可估量的作用。
这些能力应该被结构化、显性化，并开放给所有人。

因此，InterCog 的所有模块都是可读、可扩展、可协作的。

你的贡献将帮助 AI 更好地理解世界，也帮助更多人获得跨学科推理能力。

2. 可贡献的内容类型
你可以贡献以下内容：

第1. 新的跨学科分析场景（scenarios.json）
例如：

环境政策分析

城市规划研判

教育体系评估

国际关系解读

文化研究框架

场景越多，InterCog 的适用范围越广。

第2. 新的深层学科与元学科（disciplines_index.json + disciplines_graph.json）
你可以补充：

新的学科节点

学科之间的关联图谱

学科的描述与边界

学科的应用场景

InterCog 的跨学科能力依赖这些结构。

第3. 新的证据类型或权重逻辑（evidence_weights.json）
例如：

新增“跨文化研究”证据类型

优化权重排序逻辑

添加新的偏差来源说明

这能让 AI 的分析更严谨。

第4. 新的输出模板（output_templates.json）
例如：

教育政策分析模板

城市规划模板

组织行为分析模板

文化研究模板

模板决定了 AI 的结构化输出方式。

第5. 新的神经系统适配规则（neuro_profile.json）
例如：

新增“高敏感人群”适配

新增“结构化思维偏好者”适配

新增“高抽象能力用户”适配

这能让 InterCog 更具人性化。

第6. 使用案例（demo_cases.md）
你可以分享：

你用 InterCog 解决了什么问题

哪个场景最有帮助

哪个学科组合最有效

哪些输出让你印象深刻

真实案例能帮助更多人理解 InterCog 的价值。

第7. 文档改进（README、指南、教程）
任何文档改进都非常欢迎：

更清晰的说明

更好的示例

更友好的入门指南

更完整的学科解释

文档是开源项目的生命线。

3. 贡献前的准备
在提交贡献前，请确保你已经：

阅读了 README

理解 InterCog 的模块结构

熟悉 JSON 文件的格式

明白每个模块的作用

遵守 MIT 协议精神

遵守版权与合规边界

如果你不确定某个贡献是否合适，可以先提交 Issue 讨论。

4. 如何提交贡献
步骤 1：Fork 仓库
点击仓库右上角的 Fork 按钮。

步骤 2：创建新分支
Code
git checkout -b feature/your-feature-name
步骤 3：进行修改
你可以修改：

JSON 模块

文档

示例

配置

步骤 4：提交修改
Code
git commit -m "Add: 新增某某学科/场景/模板"
步骤 5：发起 Pull Request
请在 PR 中说明：

你做了什么

为什么这样做

对 InterCog 的价值

是否需要进一步讨论

我们会尽快 review。

5. 贡献质量标准
为了保持 InterCog 的专业性，我们建议贡献遵循以下标准：

学科贡献标准:
必须有清晰的学科定义

必须有明确的边界

必须有可验证的来源（公开资料）

必须有图谱关联（graph）

场景贡献标准:
必须是无标准答案的抽象问题

必须涉及多学科

必须有结构化输出需求

必须能被用户真实使用

证据贡献标准:
必须标注来源类型

必须符合公开资料原则

不得包含付费内容原文

模板贡献标准:
必须结构清晰

必须适配场景

必须包含局限性声明位置

6. 合规与版权要求（必须遵守）
InterCog 不接受任何包含以下内容的贡献：

付费数据库原文

付费论文原文

受版权保护的书籍或新闻的完整段落

未公开的专利或内部文档

商业机密

违法违规内容

医疗诊断、法律裁决、投资建议等刚性决策内容

所有贡献必须基于公开资料。
