
CODE_OF_CONDUCT.md — InterCog 行为准则
前言（Purpose）
InterCog 是一个跨学科推理框架，致力于让深层学科与元学科的力量成为所有人的基础设施。
为了确保社区安全、开放、友善、专业，我们制定了本行为准则。

所有参与 InterCog 的贡献者、使用者、维护者都必须遵守本准则。

1. 我们的承诺（Our Commitment）
我们承诺为所有参与者提供一个：

安全、尊重、包容、无歧视、无骚扰、支持跨学科交流、鼓励知识共享 的社区环境。

我们致力于构建一个让每个人都能自由贡献、自由讨论、自由探索的空间。

2. 我们倡导的行为（Positive Behaviors）
我们鼓励所有参与者：

尊重不同学科、不同文化、不同认知方式

以开放的态度讨论复杂问题

在跨学科交流中保持耐心与好奇心

主动帮助新贡献者理解框架结构

在提出批评时保持建设性

在贡献内容时保持严谨、透明、可验证

在讨论敏感议题时保持专业与克制

尊重所有人的时间、精力与劳动成果

InterCog 的核心是跨学科合作，因此我们特别鼓励：

经济学、社会学、心理学、认知科学、系统论等深层学科的贡献

方法论、证据学、复杂系统分析等元学科的贡献

不同领域之间的知识碰撞与互补

3. 不被允许的行为（Unacceptable Behaviors）
以下行为在 InterCog 社区中严格禁止：

人际行为方面
任何形式的骚扰、侮辱、攻击性言论

任何形式的歧视（种族、性别、性取向、宗教、文化等）

恶意挑衅、故意制造冲突

传播仇恨、暴力或极端内容

侵犯隐私或泄露他人个人信息

学术与内容方面
伪造数据、捏造证据、误导性引用

未经许可复制付费内容或受版权保护内容

贡献违反版权、法律或伦理的内容

故意破坏 JSON 模块结构或提交恶意代码

贡献不符合 InterCog 深层学科与元学科精神的内容

技术与合规方面
试图绕过版权保护、付费墙或访问限制

试图利用 InterCog 生成违法违规内容

试图让 InterCog 参与医疗诊断、法律裁决、投资建议等刚性决策

试图让 InterCog 输出敏感、危险或不可控的内容

4. 贡献者的责任（Contributor Responsibilities）
所有贡献者应：

确保贡献内容基于公开资料

确保引用来源真实、可靠、可验证

确保新增学科、场景、模板符合 InterCog 的结构规范

确保讨论保持专业、友善、跨学科精神

在不确定时主动寻求澄清

尊重维护者的决策

遵守 MIT 协议精神

5. 维护者的责任（Maintainer Responsibilities）
维护者应：

公平、透明地 review 所有贡献

在拒绝贡献时提供清晰理由

保护社区免受骚扰、歧视、攻击性行为

在冲突中保持中立、专业

维护 InterCog 的跨学科精神与结构完整性

在必要时采取行动，包括警告、限制参与、移除贡献等

6. 冲突处理（Conflict Resolution）
如果你遇到：

不当行为

骚扰

歧视

恶意贡献

社区冲突

请通过 Issue 或私信方式联系维护者。

维护者将：

认真倾听

公正处理

保护举报者隐私

在必要时采取行动

7. 适用范围（Scope）
本行为准则适用于：

仓库内的所有互动

Issue、PR、讨论区

社区聊天频道

与 InterCog 相关的任何公共空间

8. 许可（License）
本行为准则基于 MIT 开源精神制定。
所有贡献者必须遵守本准则才能参与 InterCog 的建设。

9. 社区愿景（Community Vision）
InterCog 的目标不是构建一个工具，而是构建一个：

跨学科、跨文化、跨认知的开放知识生态。

我们相信：

深层学科能帮助人类理解复杂世界

元学科能帮助人类构建更好的推理结构

开源能让这些能力属于所有人

我们邀请你与我们一起构建这个未来。
